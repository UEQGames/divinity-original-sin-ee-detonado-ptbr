# Divinity: Original Sin — Enhanced Edition — Detonado Interativo PT-BR

**▶ Abrir o detonado online:** https://ueqgames.github.io/divinity-original-sin-ee-detonado-ptbr/

Detonado interativo em português do Brasil para **Divinity: Original Sin — Enhanced Edition**.

## Recursos
- Rotas e objetivos organizados por campanha.
- Conquistas, builds, mapas e referências.
- Progresso salvo localmente.
- Exportação/importação de save do guia.
- Modo Rota, busca e painéis de acompanhamento.
- Interface responsiva para desktop e celular.

## Uso offline
Baixe a Release, extraia os arquivos e abra `index.html`.

Projeto independente de fãs, sem afiliação oficial com a Larian Studios.
